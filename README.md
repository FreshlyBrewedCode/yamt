# yamt

Yet another macro tracker: a personal, agent-driven meal and macro log.

Capture is freestyle and low-effort (voice memos, photos, text, recipe links, grouped per meal in a
small PWA). An agent, driven over ACP, analyses each meal afterwards: it transcribes, reads the
photos, grounds every ingredient in a nutrition database (Open Food Facts, USDA FoodData Central)
and logs macros with their provenance. Raw captures are kept forever so any meal can be
reprocessed.

Status: early development. Background research: [reports/](reports/).
